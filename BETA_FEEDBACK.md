# Job Radar Beta Feedback

Thanks for testing Job Radar. This beta is meant to find the places where the app feels confusing, fragile, or untrustworthy before it is shared more widely.

Please do not include private API keys, resumes, cover letters, or sensitive personal documents in feedback. Source URLs and screenshots are useful, but redact anything you would not want in a public GitHub issue.

## Best Test Path

Try this flow first:

1. Install the DMG.
2. Open Job Radar from Applications.
3. Complete onboarding.
4. Add 3-5 career pages or RSS feeds you actually care about.
5. Run the first scan.
6. Review Jobs and Sources.
7. Shortlist, reject, or mark one job as applied.
8. Create a note.
9. Create a backup ZIP.
10. Quit and reopen the app.

## What To Report

The most useful reports are specific:

- macOS version
- app version
- what you were trying to do
- what happened
- what you expected
- whether restarting helped
- screenshots, if helpful
- source URLs that failed, if they are public

## High-Priority Problems

Please report these even if you are short on time:

- app will not open
- macOS warning is confusing or scary
- blank window or backend unreachable message
- onboarding gets stuck
- scan never finishes
- source says it worked but no jobs appear
- source failure is unclear
- job ranking feels misleading
- backup/export fails
- restore fails
- anything that makes you worry about privacy or data loss

## Product Feedback

Bug reports are great, but product reactions are just as useful:

- What felt immediately useful?
- What felt confusing?
- What made you trust or distrust the app?
- Which screen felt least polished?
- What would need to improve before you would use this weekly?
- What would need to improve before you would pay for it?
